# UE19 Lab 05 – Application JokeAPI

Cette application interroge l'API publique [JokeAPI](https://v2.jokeapi.dev/) pour afficher une blague aléatoire en ligne de commande.

---

## ⚒️ Installation

### 1. Cloner le dépôt
```bash
git clone https://github.com/q240094/ue19-lab-05.git
cd ue19-lab-05
```

## 🚀 Lancement

### 1. Constuire le conteneur
```bash
docker build -t ue19-lab-05 .
```

### 2. Exécuter le conteneur
```bash
docker run --rm ue19-lab-05
```
